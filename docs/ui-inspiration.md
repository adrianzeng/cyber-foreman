# 前端重塑设计备忘录（v1.0.0 之后演进蓝图）

> 本文沉淀自开源多 Agent 工作台与像素可视化项目的调研灵感（**T3 Code**、**AionUi**、**VibeValley**、**Star-Office-UI**），结合本项目「完全独立运行的本地多 Agent 调度中台、扁平化老板直派、零构建轻量分发」的定位，作为 `v1.0.0` 封版后的前端重塑设计蓝图。

---

## 一、 核心设计原则

1. **扁平化直管（无强制总控/总经理层）**：用户即老板，直接面向每个项目与每个 CLI 员工下发任务、插话纠偏、查岗侧问；MCP 主控（WorkBuddy / 豆包工作 / DSH）作为可选外接大脑，而非唯一入口。
2. **能看更能派活**：不仅展示状态动画，每一次点击都要能直接落到真实的本地任务控制（派发、插话、侧问、停止、重派、换员工）。
3. **坚持零构建静态托管 + 离线可用**：前端保持原生 HTML/CSS/JS + 本地化资源，不依赖公网 CDN，保留 `npx` 轻量一键启动体验。
4. **版权红线**：绝不搬运任何第三方非商用美术资产；视觉素材采用原创像素精灵或明确 CC0/MIT 商用许可资源，并预留「角色 / 场景 / 装饰」可替换槽位。

---

## 二、 吸收自四个参考项目的五大核心能力

### 1. 双视图切换（借鉴 Star-Office-UI + 现有工单流）
- **工单工作台视图（效率模式）**：保留三栏高密度结构（左项目员工 / 中派活与行式任务流 / 右详情与对话），适合高频日常开发与精准排查日志。
- **2D 像素「办公室」视图（沉浸/演示模式）**：
  - 俯视角三区布局：**休息区沙发**（`idle` 摸鱼/喝咖啡）、**工作区工位**（`running` 敲键盘，按 `Read/Grep` 翻资料、`Write/Edit` 写代码、`Bash` 冒汗跑终端细化动作）、**Bug 区**（`waiting` / `failed` 蹲下举牌报错）。
  - **即时动作反馈（依赖后端补齐 SSE `/api/events`）**：派活瞬间员工从沙发起身跑向工位；收到老板 `steer` 插话弹出惊叹号并加速冒汗；完成后工位举手交差再回沙发。
  - **交互闭环**：点沙发牛马 = 直接派活；点工位牛马 = 滑出查岗/插话抽屉；点 Bug 区牛马 = 一键拍桌返工或标记已处理；鼠标悬停直接浮窗展示今日战绩（完成数、失败数、token 用量）。

### 2. 右侧产物实时预览面板（借鉴 T3 Code）
- 现有右栏以纯文本 `<pre>` 显示最终回报与原始日志；后续升级为多 Tab 产物预览器：
  - **Diff 变更预览**：对比任务前后工作区文件变更（`git diff` / 文件摘要），一眼看清员工改了哪几行。
  - **Markdown / 报告渲染**：直接渲染员工生成的 `.md` 文档、表格与代码块，支持一键复制或打开本地文件。
  - **实时终端/工具流**：结构化折叠展示每次工具调用（Read / Edit / Bash）的耗时与状态，替代生啃原始 JSONL 日志。

### 3. 任务中途热切换员工 — Handoff（借鉴 AionUi）
- 场景：Claude 写完架构方案后想交给 Codex 跑重度重构，或者某个模型卡住/额度耗尽想无缝换 Antigravity / Kimi 接棒。
- 设计方案：
  - 在任务详情提供 **「交接给另一员工（Handoff）」** 动作；
  - 后端自动汇总原任务目标、最近进度、产出摘要与工作目录，生成结构化交接上下文包；
  - 为目标员工创建关联子任务（`handoffFromTaskId`），保持原有单员工串行边界与会话隔离不互相污染。

### 4. 可选 Git Worktree 隔离（借鉴 T3 Code）
- 痛点：当前后端保证「单员工串行」，但不限制两个不同员工同时修改同一个项目目录，并行改代码时容易互相覆盖。
- 设计方案：
  - 在员工或派活高级选项提供 **「隔离工作树（Git Worktree）」** 开关（默认关闭，保持简单心智）；
  - 开启后，派活前自动在 `.hub-worktrees/<taskId>` 检出独立分支，任务结束后在右侧预览面板展示分支 Diff，并提供「合并回主分支 / 丢弃工作树」按钮。

### 5. 每日工作小记（借鉴 Star-Office-UI + VibeValley）
- 基于本地落盘的 `data/tasks/*.json` 与 `data/events.jsonl`，自动按天生成一份简洁的「每日工作小记」卡片：
  - 汇总今日各项目完成了哪些任务、哪位员工产出最多、哪些卡点待处理、总输出 token 与耗时；
  - 支持脱敏后一键导出 Markdown 或定时通过 Telegram / 飞书 / QQ / 微信推送日报，也天然适合自媒体演示录屏收尾。

## 三、 后端预留衔接点

为平滑过渡到上述前端重塑，后端将在 `v1.0.0+` 阶段补充以下最小增量接口（不破坏现有 `/api/*` 契约）：
- `GET /api/events`：轻量 SSE 事件流，推送细粒度 `progress`、`steer`、`status/stage` 变化驱动像素办公室动画。
- `GET /api/tasks/:id/diff`：在 git 仓库工作区下返回只读变更摘要与文件列表。
- `POST /api/tasks/:id/handoff`：生成交接上下文并派发给目标员工。
- `GET /api/digest?date=YYYY-MM-DD`：聚合当日工作小记数据。
